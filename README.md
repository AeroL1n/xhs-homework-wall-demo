# 作业墙 · 种草笔记里的「同题实践者」· 交互 Demo

小红书笔记详情页的功能创意：评论区顶部增加"作业墙"入口条。用户照常发自己的成果图，系统识别后归入这条笔记专属的作业墙，看同一篇笔记的人从陌生读者变成做了同一件事的「同题实践者」。关系只存在于这一篇笔记里，不加好友，不建新的消息通道。

**可交互链接：<https://aerol1n.github.io/xhs-homework-wall-demo/>**

建议用电脑浏览器打开。页面是单文件 HTML，左侧是说明与关系视图，右侧是可点击的手机框。

## 怎么玩

1. 页面打开时，左侧关系视图先显示所有人各自只连向笔记的孤立状态，约 1.6 秒后已交作业的人聚拢成圈。点右上角「回看互动前」可重播。
2. 点「看 30 秒演示」，按分步旁白走完发作业、入墙、关系变化的全过程。
3. 点「自己试试」，在手机里从评论区发一份作业，观察入口条数字、小标和关系视图同步更新。
4. 进入作业墙翻看他人作业，点开详情对照原作，用追问芯片在作业下发出复刻追问，可撤回。
5. 点「模拟 14 天后」，查看关系淡出的状态。

## 说明

- 示例笔记是虚构的「秋日奶茶眼妆」，图片用渐变色块和线稿占位，昵称与头像也是虚构的。
- 不含真实识别算法和真实数据，识别结果为脚本演示。
- 无外部依赖，所有状态保存在页面内存里，刷新后回到初始状态。
- 本地查看：下载 `index.html` 后双击打开即可。
